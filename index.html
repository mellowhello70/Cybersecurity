Reflection

  1. The most significant layout issue I discovered was that the content needed to adapt better to smaller screens.
  2. I used flexible widths, max-width, padding, margins, box-sizing, and a CSS media query to improve the layout.
  3. At wider widths, the navigation links appear beside each other. At narrower widths, they stack vertically to make the website easier to use.
  4. Testing different viewport widths taught me that responsive design involves more than shrinking a page. Text, images, and navigation must remain usable.
  5. One improvement I would make next is to test the website on more devices and improve any sections that feel crowded on smaller screens.
